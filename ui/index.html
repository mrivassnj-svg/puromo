1. Crawl / Lookup
not run
Input: a known HAT, a search query + vendor, or custom PCB dimensions (sidebar). Output: a device spec JSON.
2. Dimensions
not run
Input: device spec. Output: backend ShellGeometry (single source of truth), 3D preview, 2D preview, fit/tolerance warnings.
3. Modular Build
not run
Input: spec + geometry. Output: modular build manifest, assembly specs, BOM + filament, pinout, wiring. (Pinout/wiring and assembly live here: they describe how the modular build is wired and assembled, and are produced by the build/spec/pinout calls in this stage.)
4. Blender STL
not run
Input: spec + backend geometry JSON. Output: STL / .blend files and the Blender log. Skipped (not failed) when Blender is not installed.
5. Firmware
not run
Input: spec. Output: generated firmware tree (14 Python files + README) and its architecture view.
6. PDF Report
not run
Input: spec + geometry + pinout + assembly specs. Output: PDF design report (cover + TOC + 10 numbered sections).
7. Print
not run
Input: STL files in output/ + a printer choice. Output: a single print-package ZIP. Run Pipeline never uploads to or starts a physical printer.

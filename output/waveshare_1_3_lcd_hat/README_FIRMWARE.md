## Cooperative Scheduler
**Model:** asyncio (single-threaded cooperative, Python 3.11+)

| Task | Interval | Priority | CPU% |
|---|---|---|---|
| `display_render_task` | 33ms | HIGH | 40% |
| `input_poll_task` | 10ms | HIGH | 10% |
| `app_logic_task` | 33ms | NORMAL | 35% |
| `battery_task` | 1000ms | LOW | 2% |
| `imu_task` | 20ms | NORMAL | 8% |
| `watchdog_task` | 5000ms | SYSTEM | 1% |

**SPI lock:** `asyncio.Lock() — all SPI transactions must acquire before CS assert`
**I2C lock:** `asyncio.Lock() — shared bus; acquire before every transaction`

### Scheduler Notes
- No task may hold the SPI lock for more than 2ms (display DMA excepted).
- Input events are queued in asyncio.Queue(maxsize=32) — never dropped.
- Display render is double-buffered: draw to back buffer, flip on vsync.
- All blocking I/O wrapped in asyncio.to_thread() if unavoidable.
- SystemShutdown event triggers ordered teardown (reverse of boot order).

## Safety Rules
1. **Never** touch GPIO before Phase 0 completes.
2. **Always** assert CS HIGH before switching SPI devices.
3. **Always** acquire the SPI lock before any SPI transaction.
4. **Never** call `time.sleep()` inside an async task — use `await asyncio.sleep()`.
5. **Never** do direct module-to-module calls after Phase 9 — use EventBus only.
6. **Always** run cleanup (GPIO.cleanup, SPI.close) in the `finally` block of main.
